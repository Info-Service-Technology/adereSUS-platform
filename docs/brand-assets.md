# Ativos da marca AdereSUS

As imagens oficiais ficam em `apps/web-professional/public/brand` com nomes estáveis. Os arquivos recebidos permanecem preservados visualmente; a aplicação não depende dos nomes originais com espaços ou sufixos.

| Arquivo no projeto | Uso recomendado |
| --- | --- |
| `aderesus-horizontal.png` | login, cabeçalho, barra lateral expandida e página institucional |
| `aderesus-stacked.png` | áreas compactas, tela de abertura, ícone provisório e materiais quadrados |
| `aderesus-stationery.png` | documentos, propostas, capas e papelaria |
| `aderesus-campaign.png` | página institucional, apresentação e comunicação com fundo claro |
| `aderesus-campaign-transparent.png` | composição sobre fundos controlados e materiais gráficos |

## Regras de uso

- não distorcer a proporção;
- não recortar o símbolo ou o nome sem uma variante oficial própria;
- não aplicar outras cores ou efeitos sobre a marca;
- preservar área livre ao redor;
- preferir a versão horizontal no portal;
- usar a marca empilhada somente quando a largura for limitada;
- imagens de campanha não devem substituir a identidade funcional de botões, menus ou pequenos ícones;
- a peça transparente exige teste de contraste no fundo escolhido;
- novos formatos otimizados deverão ser derivados dos arquivos oficiais e documentados.

## Uso atual

- a tela de login utiliza `aderesus-horizontal.png`;
- o navegador utiliza provisoriamente `aderesus-stacked.png` como ícone;
- as demais versões estão disponíveis para as próximas telas e documentos.
